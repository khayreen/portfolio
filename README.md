## Built with

Plain HTML, CSS and vanilla JavaScript. No framework, no build step, no dependencies —
the whole site is a single `index.html` plus five images, about 302 KB total.

## Features

- **Parallax pixel-art background** — four layers scrolling at different rates,
  scaled by whole-number multiples so the pixel grid stays crisp at any viewport size
- **Accessible by design** — WCAG AA contrast throughout, skip link, visible focus
  rings, semantic landmarks, `prefers-reduced-motion` respected
- **Copy-to-clipboard contact** with three fallback tiers, so it never fails silently
- **Responsive** from 390 px upward
- **Open Graph and Twitter Card** tags for link previews

## Structure

```
index.html                     the entire site
assets/images/
  og-card.png                  social link preview (1200x630)
  parallax/                    background layers (192 px native, upscaled)
```
